SwiftAgent v0.6.0 is the first release built around an agent-neutral control
room: Claude Code, Codex, OpenCode, ACP v1 agents, and a restricted generic
command share one run model without pretending their features are identical.

## Tagged installation

The release asset `swiftagent-v0.6.0.tar.gz` includes the source and prebuilt web
client. `SHA256SUMS`, an SPDX JSON SBOM, and GitHub build/SBOM attestations are
published beside it. See `docs/INSTALL_RELEASE.md` for verification and the
Python-only runtime install.

## Highlights

- Agent registry, capability-aware UI, normalized events, native metadata, and
  durable agent identity across history.
- Native Codex app-server v2, ACP-first OpenCode, isolated Claude Code, generic
  ACP, and restricted literal-command integrations.
- Local Run Receipts with safety layers, Git impact, explicit verification, and
  JSON/Markdown export.
- Reviewed, expiring cross-agent handoffs with visible redaction and no native
  session transfer.
- Adapter API 1.0, public contract kit, visible trust labels, issue forms, and
  reproducible three-agent demo.

## Compatibility credits

## Known boundaries

- Strict external isolation requires usable Linux Bubblewrap; explicit fallback
  mode is not OS isolation.
- Claude live compatibility is not claimed when its version probe fails.
- Attachments and some native fork/mode controls remain partial or absent in the
  UI even when an underlying protocol advertises them.
- This release is local and single-user. It has no remote multi-user auth model.
- Broad promotion waits for five opt-in, redacted real-workflow reports across
  at least two agents. Silent telemetry is not used.
