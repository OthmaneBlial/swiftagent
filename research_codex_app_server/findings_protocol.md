# Codex app-server findings

Researched on 2026-08-26 from the official OpenAI app-server documentation and
the schemas generated by the locally installed `codex-cli 0.149.1`.

## Transport and lifecycle

- Local app-server defaults to stdio and emits one headerless JSON-RPC 2.0
  object per JSONL line.
- A client must send `initialize`, then the `initialized` notification before
  other requests.
- `thread/start` creates native history, `thread/resume` loads it, and
  `turn/start` begins one prompt. `turn/completed` is the terminal source of
  truth; `turn/interrupt` is the graceful cancellation request.
- Notifications stream agent-message deltas, item lifecycle, command output,
  file diff, plan, usage, warnings, errors, and final turn status.

## Authentication and models

`account/read` exposes whether the active provider requires OpenAI auth and
whether an account is present. SwiftAgent consumes that readiness signal only;
it does not invoke account login methods or accept credentials. `model/list`
is bounded to 100 visible entries and the selected model remains adapter-local.

## Approval and safety mapping

Command execution, file changes, and requested permission profiles arrive as
server-initiated requests. The existing SwiftAgent approval UI can safely map
one-shot user decisions to `accept` or `decline`; it does not silently create
session-wide grants or policy amendments.

Codex's native `approvalPolicy` and `sandboxPolicy` are independent from
SwiftAgent Bubblewrap isolation. The default maps to `on-request`, reviewer
`user`, and `workspaceWrite` with network disabled. The native combination
`never` plus `dangerFullAccess` requires a separate explicit confirmation.

## Test boundary

The deterministic fixture implements no model call and reads no credentials.
It covers handshake, auth readiness shape, models, thread start/resume, turn
start/interrupt, accepted and rejected approvals, tool failure, unknown
notifications, usage, terminal states, and malformed JSON. A free local
handshake against the installed app-server separately verifies initialize,
account, and model-list compatibility.

Official source: [Codex app-server](https://learn.chatgpt.com/docs/app-server).
